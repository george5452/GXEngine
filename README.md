### Create without limits.

GXEngine is being rebuilt from the ground up in Rust, moving beyond its original web-based architecture toward a native, high-performance game engine.

Our vision is to combine the accessibility of Godot with the cinematic ambitions of Unreal Engine, while keeping game development approachable.

---

## What's New?

- Native Rust architecture
- GPU-accelerated cinematic rendering
- SDF-based indirect lighting
- Real-time reflections and shadows
- Rapier 3D physics
- First-person and third-person player controllers
- Integrated scene editor
- Transform gizmos
- GXStarter content library
- Project and scene management

## Getting Started

Install Rust and clone the rebuild branch:

```sh
git clone -b rust https://github.com/george5452/GXEngine.git
cd GXEngine
cargo run --release
```

## The Future of GXEngine

The Rust rebuild is currently experimental and under active development. If it proves successful, it may become the primary version of GXEngine, replacing the original Electron-based architecture.

Expect bugs, experimental features, architectural changes and frequent improvements.

This isn't just a port. It's a new foundation.
