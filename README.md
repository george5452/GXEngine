### Create without limits.

GXEngine is an experimental 3D game engine designed to make game development accessible, creative and enjoyable.

Built using Electron, PlayCanvas and Rapier, GXEngine brings powerful game creation tools into a unified desktop editor — allowing creators to turn ideas into playable experiences.

## Features

- Interactive 3D scene editor
- WebGPU and WebGL rendering
- Cinematic post-processing
- Rapier 3D physics
- Blueprint visual scripting
- First-person and third-person controllers
- Professional transform gizmos
- GLB model and texture importing
- GXStarter materials and prefabs
- Built-in project templates
- Integrated content browser
- HTML, ZIP and Windows executable exporting

## Getting Started

Install Node.js and clone the repository:

```bash
git clone https://github.com/george5452/GXEngine.git
cd GXEngine
npm install
npm start
```

To package the editor for Windows:

```bash
npm run build
```

## A New Generation Is Coming

GXEngine is undergoing an experimental rebuild in Rust, introducing a completely native architecture, custom GPU rendering and a new foundation for future development.

The original Electron edition remains available, but it may eventually be replaced by the Rust rebuild if the new architecture proves successful.

**Explore the next generation: [GXEngine — Rust Rebuild](https://github.com/george5452/GXEngine/tree/rust)**

## Development Status

This edition represents the original foundation of GXEngine. Development priorities may gradually shift toward the Rust rebuild.

Both versions share the same vision: making powerful game creation accessible to everyone.
